# 상세 실습 일지

이 디렉터리에는 ROS 2 실습을 진행한 순서와 의미 있는 터미널 출력을 날짜별로 기록한다.

`notes/`가 개념과 결과를 정리한 학습 노트라면, `archive/`는 나중에 같은 실습을 다시 따라 할 수 있도록 구체적인 과정을 남기는 공간이다.

## 기록 원칙

- 실제 Raspberry Pi에서 실행한 명령만 검증 완료로 기록한다.
- 명령어를 실행한 이유와 관찰한 결과를 함께 적는다.
- 터미널 출력은 의미 있는 부분만 발췌한다.
- 전체 원본 출력이 필요하면 Git에 포함되지 않는 `logs/`에 저장한다.
- 비밀번호, 토큰, 민감한 네트워크 정보는 기록하지 않는다.
