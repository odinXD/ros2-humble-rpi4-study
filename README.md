# ROS 2 Humble Raspberry Pi Study

## Environment

- Board: Raspberry Pi 4B
- OS: Ubuntu Desktop 22.04 LTS 64-bit
- ROS: ROS 2 Humble
- Workspace: ~/ros2_ws

## Build

```bash
cd ~/ros2_ws
colcon build --symlink-install
source install/setup.bash
```

## Test

Terminal 1:

```bash
ros2 run demo_nodes_cpp talker
```

Terminal 2:

```bash
ros2 run demo_nodes_py listener
```

## Notes

- `build/`, `install/`, `log/` are generated by colcon.
- Source packages are stored in `src/`.
- ROS 2 environment is loaded from `/opt/ros/humble/setup.bash`.
